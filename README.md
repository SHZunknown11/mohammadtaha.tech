# mohammadtaha.tech

An earlier version of my personal portfolio site: static HTML, CSS and JavaScript with scroll animations, a web app manifest, `robots.txt`, a sitemap and JSON-LD structured data.

**[▶ View this version](https://shzunknown11.github.io/mohammadtaha.tech/)**

> My current portfolio is at **[mohammad-taha-portfolio.pages.dev](https://mohammad-taha-portfolio.pages.dev)**.

## Structure

| Path | Holds |
|---|---|
| `index.html` | The whole page, with meta tags and structured data |
| `css/style.css` | Styles |
| `js/main.js` | Animations and interactions |
| `manifest.json`, `robots.txt`, `sitemap.xml` | PWA and search-engine files |

## Run locally

Clone the repo and open `index.html` in a browser.
